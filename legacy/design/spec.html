PySide6 實作對照

每個視覺元素對應的 Qt 作法。整份樣式集中在單一 QSS 字串，色票以 Python dict 供應，切換主題只換 dict 再重新套用。

畫面元素Qt 作法要注意的地方
側欄 / 參數面板 QFrame + objectName QSS 用 #objectName 選取，避免樣式外溢到子控制項
對話列表 QListWidget + 自訂 item widget 選取態的左側藍條用 border-left: 3px 畫
訊息串 QScrollArea + 每則一個 widget 串流時只更新最後一個 widget，不重建整串
使用者氣泡 QLabel 包在靠右的 QHBoxLayout 四角不等圓角 QSS 支援；需 setWordWrap(True)
助理回覆（Markdown） QTextBrowser + setMarkdown() 高度要跟著內容長，關掉自身捲軸並綁 documentSize
思考折疊區 可摺疊 QFrame，標題列接 mousePressEvent 收合就 setVisible(False)；箭頭圖示同步換向
狀態燈 自繪 QWidget，paintEvent 畫圓點 + 光暈 連線中的呼吸效果用 QPropertyAnimation 跑透明度
思考模式四段切換 QButtonGroup 內 4 顆 QPushButton(checkable) 依 capabilities 動態增減按鈕數，不支援時整組 setEnabled(False)
取樣滑桿 QSlider + 數值 QLabel QSlider 只吃整數，浮點參數要自己乘 100 再除回來
圓角輸入框 QTextEdit 外包一層 QFrame 圓角畫在外框上，內層 QTextEdit 設透明無邊框
串流與 UI 執行緒 QThread worker + Signal 絕不從 worker 直接碰 widget；一律走 signal 回主執行緒
圖示 SVG 字串 → QPixmap 顏色寫死在 SVG 裡，換主題時重新產生一次
畫板為靜態視覺規格，非可互動原型。內容示意用的對話與統計數字為範例值，實作時由 /api/chat 的真實回傳填入。
